# example-repo

holiday.py
Plan your holiday with the holiday calculator, From flight cost to hotel and transport.

1. It Stores Prices: The program has a built-in list of flight prices for 10 South African cities. It also has two fixed daily rates (Hotel cost: R955,85 per night, Car rental cost: R550,00 per day.)

2. It Asks You for Inputs When you run the code, it interacts with you by asking three questions: Where are you going? It shows you a numbered list of cities (1 to 10) and asks you to pick a number. How long are you staying? It asks for the number of nights you need a hotel. Are you renting a car? It asks for the number of days you need a vehicle.
3. Note: The code includes "safety loops" (while True). If you accidentally type letters instead of numbers, it will gently ask you to try again rather than crashing.

4. It Does the Math Once it has your answers, it automatically calculates the subtotals:\(\text{Hotel\ Subtotal}=\text{Nights}\times \text{R955,85}\)\(\text{Car\ Subtotal}=\text{Days}\times \text{R550,00}\)It then looks up your chosen city's flight price and adds everything together to get your Total Holiday Cost.

5. It Displays the Receipt Finally, it prints out a clean, formatted receipt showing a breakdown of each expense and the grand total in Rands (R)
